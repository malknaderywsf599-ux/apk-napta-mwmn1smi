# نبتة | مساعدك اليومي

تطبيق ويب عربي متجاوب لتنظيم اليوم، يعمل محلياً على الهاتف أو الكمبيوتر.

## المميزات
- لوحة رئيسية وإحصائيات يومية.
- إضافة وتعديل وحذف المهام مع الأولوية وتاريخ الاستحقاق.
- ملاحظات قابلة للبحث والتعديل.
- سجل مصروفات بالجنيه المصري وتصنيفات.
- عادات يومية مع متابعة نسبة الإنجاز.
- مؤقت تركيز 5 أو 15 أو 25 دقيقة.
- وضع ليلي ونهاري.
- تصدير واستيراد نسخة JSON.
- حفظ تلقائي على الجهاز باستخدام LocalStorage.
- دعم العمل دون إنترنت بعد أول تحميل عبر Service Worker.

## التشغيل
1. فك ضغط الملف.
2. افتح `index.html` في متصفح حديث.
3. للحصول على دعم التثبيت والعمل دون اتصال بصورة أفضل، شغّل المجلد من خادم محلي أو استضافة HTTPS.

## تحويله إلى APK
هذا المشروع نسخة ويب/PWA وليس APK جاهزاً. يمكن تغليفه لاحقاً باستخدام Capacitor أو Android WebView داخل Android Studio. لا يحتاج المشروع إلى Termux.

## الخصوصية
البيانات تبقى في تخزين المتصفح على الجهاز. لا يوجد تسجيل دخول ولا إرسال بيانات إلى خادم.
